Place dummy audio files (mp3) using these names:
- niat/niat_{index}.mp3            # index matches doa order in Niat
- tawaf/tawaf_{round}_{index}.mp3  # round is 0..6, index per doa in that round
- sai/sai_{round}_{index}.mp3      # round is 0..6, index per doa in that round
- tahalul/tahalul_{index}.mp3      # index matches doa order in Tahalul
- tertib/tertib_{index}.mp3        # optional, if adding audio for Tertib items

Example files to start:
- niat/niat_0.mp3
- tawaf/tawaf_0_0.mp3
- sai/sai_0_0.mp3
- tahalul/tahalul_0.mp3
- tertib/tertib_0.mp3
